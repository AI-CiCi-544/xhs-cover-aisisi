# 面部特征卡（自己填，锁脸用）

> 这张卡是锁脸的核心依据。填得越具体，脸越稳；写"五官精致"这种词只会得到一张网红脸。
> 填完把内容抄进提示词的 `[Character Anchoring]` 段。

- 脸型：____（如：鹅蛋脸 / 圆脸 / 方圆脸；颧骨平缓或凸；下颌线柔和或明显）
- 眼：____（单/双眼皮；眼型横长或圆；眼尾平、上挑或下垂；瞳色）
- 鼻：____（鼻梁高低；鼻头圆润或尖；鼻翼宽窄）
- 唇：____（厚薄；唇峰明显或不明显；唇形小巧或宽）
- 皮肤：____（色调；是否保留毛孔、是否允许轻微瑕疵）
- 发型：____（长度；刘海有无与形态；一个识别点，如固定分缝、发旋）
- **识别锚点**：____（一处小特征：痣 / 疤 / 虎牙 / 耳型，必须能一眼验证"是不是本人"）

## 示例（仅供参考格式，不要照抄内容）

- 脸型：鹅蛋脸、颧骨平缓、下颌线柔和不外扩
- 眼：单眼皮偏内双、眼型横长、眼尾平不上挑
- 鼻：鼻梁不高、鼻头圆润、鼻翼窄
- 唇：唇饱满、唇峰不明显
- 皮肤：偏白、保留毛孔，不要磨皮
- 发型：长直黑发、齐刘海（识别点，别去掉）
- 识别锚点：右脸颊靠鼻翼外侧一颗小痣
