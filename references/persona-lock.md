# 人物一致性（把人锁住，别换成网红脸）

封面上的脸是账号资产。**脸不像本人，这条封面就废了**，字号再大也没用。

这个技能不含任何人的人像照片，用之前先把你自己的照片放进来。

## 一、准备你的锚点图

1. 挑一张正面、正对镜头、光线均匀的自拍或棚拍，脸部占画面 40% 以上，别侧脸、别大笑、别滤镜。
2. 存为 `assets/persona/persona-anchor.jpg`（文件名固定，提示词与流程都按这个名字找）。
3. 想换造型（短发/全身/正装）时，把额外的图放进 `assets/persona/alternates/`，命名自便，用时手动指定。

**单张锚点图是已验证最稳的路线**：模型能保住脸型与眼型。多塞几张不一定更准，反而容易"混脸"。

**关于审核**：部分自拍会被绘图工具的内容审核拦下（报 `pre bottom line review not pass`）。先用当前锚点试一次，能过就继续；被拦就换一张角度更正的，别拿同一张反复重试。

## 二、写"面部特征卡"（关键步骤）

把下面这张表填一遍，写进 `assets/persona/face-card.md`。**这张卡是锁脸的核心**，比任何"保持面部一致"的笼统指令都管用。

| 项 | 怎么写 | 例子（照这个粒度写，不要写"五官精致"） |
|---|---|---|
| 脸型 | 轮廓 + 骨相 | 鹅蛋脸、颧骨平缓、下颌线柔和不外扩 |
| 眼 | 单/双、眼型、眼尾走向 | 单眼皮偏内双、眼型横长、眼尾平不上挑 |
| 鼻 | 梁高、鼻头、鼻翼 | 鼻梁不高、鼻头圆润、鼻翼窄 |
| 唇 | 厚薄、唇峰 | 唇饱满、唇峰不明显 |
| 皮肤 | 质地与色调 | 偏白、保留毛孔，不要磨皮 |
| 发型 | 长度 + 刘海 + 一个识别点 | 长直黑发、齐刘海（识别点，别去掉） |
| **识别锚点** | 一处小特征：痣、疤、虎牙、发旋 | 右脸颊靠鼻翼外侧一颗小痣 |

**为什么必须写到这个粒度**：实测写"保持面部不变"脸会飘；写具体特征（圆脸／单眼皮内双／鼻头圆／唇厚／某处一颗痣）才锁得住，而写"精致五官、大眼睛、立体鼻梁"会直接被改成网红脸。

## 三、锁定句式（照抄，把方括号换成你卡里的内容）

> 完美保留参考图里这位真人的脸部特征，不要美化、不要改成网红脸：[脸型]；[眼型]；[鼻型]；[唇型]；**[识别锚点]**；[发型]。不要改脸型、不要削下颌、不要改成欧式大双、不要放大眼睛、不要磨皮成塑料皮肤。

识别锚点那句要单独一句写、可用粗体。模型对"某处有一颗痣"这类具体特征的响应，明显强于对形容词的响应。

## 四、允许改动（风格化边界）

- **服装**：白色衬衣领外套（和深底对比最出效果）、科技感机能外套、高领紧身衣、半透明披风
- **发型**：以锚点图为基准微调，可扎马尾、可披到肩后、可做湿发质感；不染亮色、不剃短、不要去掉你的识别点（刘海/分缝等）
- **妆面**：冷调或裸妆，可加一点金属高光或全息贴片，但不要盖掉识别锚点
- **场景**：深空、数据中心、全息舱、抽象发光几何空间；浅底则用奶油白墙面与柔光
- **强风格化**：赛博义体接口、全息投影、半透明数字分身 —— 只要**一眼能认出是你**

## 五、绝不允许

- 换脸、年龄明显变化（±8 岁以上）
- 脸型拉长成尖下巴、眼睛放大变圆、鼻梁拔高（这是最常发生的三件事）
- 网红滤镜感：过度磨皮、塑料皮肤、大眼瘦脸
- 抹掉你的识别锚点
- 手画成六指、多一条胳膊

## 六、出图后只看四处

1. **眼型**：和卡里一致，没有变成上挑的大双眼皮
2. **下颌**：和卡里一致，没有变成尖三角
3. **唇**：厚薄与唇峰没被改
4. **识别锚点**：那颗痣 / 那道疤还在不在

任一处不符 → 重新生成。不要靠后期液化硬修，修过的脸在缩略图里会"怪"。

## 七、换形象时

替换 `persona-anchor.jpg` 即可，同时更新 `face-card.md`。**旧锚图不要再拿去出新封面**，否则同一账号会出现两个"你"。
