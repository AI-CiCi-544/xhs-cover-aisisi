# 标题与文案（AI 工具 / 方法教程）

封面标题只有 1 秒的注意力预算。**先想清楚"她刷到会想点哪个"，再动手排版。**

## 六个公式（一次只用一种，别叠）

| 公式 | 模板 | 示例（`\n` 为换行） |
|---|---|---|
| 数字+结果 | N 步 / N 个 + 结果 | `3 步搭好\nAI 工作流` |
| 身份+利益 | 给谁 + 能拿到什么 | `新手也能\n跑通 Agent` |
| 反差纠正 | 你以为的 X，其实… | `你以为的 AI\n全用错了` |
| 疑问 | 为什么你的 X 不行 | `为什么你的\n提示词没用` |
| 清单留存 | N 个我一直在用的 | `5 个工具\n我留了 1 年` |
| 损失避坑 | 别再 X | `别再用\n这个 AI 工具` |

**选择顺序**：有数字 + 有反差 > 有数字 > 有身份 > 最短的。

## 硬约束

- 6-12 字最稳；16 字是上限；**最多 3 行，每行 ≥4 字**（单字成行在缩略图里像错字）
- 数字用阿拉伯数字（`3 步` 比 `三步` 醒目），中文与数字之间留空格
- 英文工具名保留原拼写：`Claude` / `GPT` / `Agent` / `MCP`；全大写更醒目
- 不放书名号、括号、双引号；需要强调用高亮块或换字色
- 不写抽象词：赋能、生态、闭环、打造、助力、全方位 —— 缩略图里等于零信息

## 副标题（只补证据，不重复主标题）

可用素材：`实测 37 个提示词` / `从 0 到上线 40 分钟` / `附可复用模板` / `3 个工具全免费`

## 徽章（左上角 pill，2 字最好）

`教程` / `实测` / `模板` / `避坑` / `合集` / `亲测`

## 高亮关键词（一期只标 1 个）

选出标题里**最能兑现承诺的那个词**上高亮（青底深字 或 琥珀字），例如：

- `3 步搭好 AI 工作流` → 高亮 `3 步`
- `5 个工具我留了 1 年` → 高亮 `1 年`
- `新手也能跑通 Agent` → 高亮 `Agent`

高亮规则：只在**一个词**上，不要整行高亮；高亮块用 `#35E0FF` 或 `#FFB020`，字用 `#04121A` 深色。
